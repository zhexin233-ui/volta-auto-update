# Volta 工具自动更新器

自动检查和更新 Volta 管理的开发工具（Codex、Claude Code、Gemini CLI）到最新版本。

## 功能特性

- ✅ 自动检查工具的当前版本和最新版本
- ✅ 一键更新所有过期的工具
- ✅ 友好的命令行界面，带 emoji 状态指示
- ✅ 支持 macOS 双击执行
- ✅ 完善的错误处理和进度显示

## 使用方法

### 方法 1：终端执行

```bash
./update-volta-tools.sh
```

### 方法 2：双击执行（macOS）

直接双击 `update-volta-tools.command` 文件即可在终端窗口中运行。

## 系统要求

- macOS 系统
- 已安装 Volta (v2.0.0+)
- 网络连接（用于查询 npm registry）

## 错误处理

脚本会自动处理以下错误情况：

- ❌ Volta 未安装：显示错误并退出
- ❌ 网络请求失败：跳过该工具，继续处理其他工具
- ❌ 工具未安装：显示警告，跳过更新
- ❌ 更新失败：记录错误，继续处理其他工具

## 技术实现

- 使用 `volta list all` 检查当前版本
- 使用 npm registry API 查询最新版本
- 使用 `volta install <package>@latest` 执行更新
- 兼容 Bash 3.2+（macOS 默认版本）
